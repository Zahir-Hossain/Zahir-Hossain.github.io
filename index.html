Scientific ML · Semantic segmentation

Multi-Temporal Crop Type Semantic Segmentation

Built a reproducible multi-temporal semantic-segmentation workflow on Sentinel-2 image sequences, comparing an engineered-feature Random Forest baseline with a compact UTAE model. Validation mIoU improved from 0.446 to 0.572; the selected model achieved 0.473 mIoU on the held-out split, with fixed folds, validation-only checkpoint selection, saved artifacts, and reproducibility checks.
